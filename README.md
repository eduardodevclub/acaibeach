# Tropical Delights Builder

Prompt — Landing Page Profissional para Sorveteria & Açaí

Crie uma landing page moderna, profissional, visualmente impactante e totalmente responsiva para uma empresa fictícia chamada Açaí Tropical, uma sorveteria e açaiteria especializada em açaí, sorvetes, milk-shakes e acompanhamentos.

A página deve ter aparência de um negócio real, com foco em vendas, pedidos pelo WhatsApp e conversão de visitantes em clientes.

1. Identidade visual

Criar uma identidade visual jovem, tropical, refrescante e apetitosa.

Estilo:

Moderno

Alegre

Tropical

Premium, mas acessível

Visual limpo

Forte apelo gastronômico

Utilizar uma combinação visual inspirada em:

Roxo/açaí

Branco

Tons de amarelo ou laranja

Pequenos detalhes em verde

Utilizar tipografia moderna, arredondada e fácil de ler.

A interface deve transmitir imediatamente a sensação de verão, frescor e sobremesa gelada.

2. Hero Section

Criar uma primeira seção extremamente atrativa.

Título principal:

"Seu momento mais gostoso começa aqui!"

Subtítulo:

"Açaí cremoso, sorvetes irresistíveis e combinações do seu jeito. Monte seu copo e aproveite!"

Adicionar dois botões:

"Pedir pelo WhatsApp"

"Ver nosso cardápio"

Adicionar uma imagem de alta qualidade de um copo de açaí extremamente apetitoso, com frutas, granola e acompanhamentos.

Adicionar elementos visuais tropicais discretos, como frutas, folhas e formas orgânicas.

Criar pequenas informações de confiança:

⭐ 4,9/5 de avaliação

🥤 Produtos preparados na hora

🚀 Entrega rápida

❤️ Feito com carinho

3. Cardápio

Criar uma seção chamada:

"Escolha seu favorito"

Mostrar cards de produtos com imagens grandes e apetitosas.

Categorias:

Açaí

Açaí Tradicional

Açaí com Morango

Açaí Tropical

Açaí Especial

Sorvetes

Casquinha

Copo

Sorvete Especial

Milk-Shakes

Chocolate

Morango

Ovomaltine

Nutella

Cada card deve apresentar:

Foto

Nome

Pequena descrição

Preço

Botão "Pedir agora"

O botão deve abrir o WhatsApp com uma mensagem já preenchida relacionada ao produto.

4. Monte seu Açaí

Criar uma seção interativa chamada:

"Monte seu açaí do seu jeito!"

Mostrar visualmente as etapas:

1. Escolha o tamanho

300ml
500ml
700ml
1 litro

2. Escolha a base

Açaí

Açaí + Sorvete

3. Escolha seus acompanhamentos

Leite em pó
Leite condensado

Coco

Chocolate
Confetes

4. Finalize seu pedido

Botão:

"Montar meu açaí"

A experiência deve parecer simples e divertida.

5. Combos

Criar uma seção:

"Combos que valem a pena"

Criar 3 cards:

Combo Tropical

Açaí + 3 acompanhamentos + bebida

Combo Casal

2 açaís + 6 acompanhamentos

Combo Família

Açaí de 1 litro + acompanhamentos

Cada card deve possuir:

Imagem

Nome

Descrição

Preço

Botão "Quero esse combo"

6. Diferenciais

Criar uma seção destacando por que comprar na Açaí Tropical.

Cards:

🍓 Ingredientes selecionados

🥭 Frutas fresquinhas

🥤 Preparado na hora

⚡ Entrega rápida

💜 Muito sabor em cada colherada

7. Avaliações

Criar seção:

"Quem experimenta, recomenda!"

Adicionar 4 avaliações fictícias com aparência realista.

Exemplo:

"Simplesmente maravilhoso! O açaí é muito cremoso e os acompanhamentos são bem servidos."

— Mariana S.

Criar estrelas e avatar circular para cada avaliação.

8. Galeria

Criar uma galeria visual com fotos de:

Açaí

Sorvetes

Milk-shakes

Frutas

Combos

Ambiente da loja

Utilizar imagens de alta qualidade e livres para uso, preferencialmente de bancos como Unsplash ou Pexels.

Não utilizar imagens genéricas de baixa qualidade.

9. Delivery

Criar uma seção de destaque:

"Bateu aquela vontade?"

Texto:

"Peça seu açaí, sorvete ou milk-shake sem sair de casa."

Adicionar:

"Pedir pelo WhatsApp"

Mostrar informações:

📍 Entregamos em toda a região
🕐 Funcionamento: 14h às 23h
💳 Pix, cartão e dinheiro

10. Localização

Criar seção:

"Estamos pertinho de você!"

Adicionar mapa utilizando Google Maps.

Informações:

📍 Rua Exemplo, 123 — Centro
📞 (85) 99999-9999
🕐 Segunda a domingo — 14h às 23h

Adicionar botão:

"Como chegar"

11. WhatsApp flutuante

Adicionar botão flutuante de WhatsApp no canto inferior direito.

Ao clicar, abrir conversa com mensagem:

"Olá! Vim pelo site e gostaria de fazer um pedido. 🍧"

O botão deve permanecer visível durante a navegação.

12. CTA final

Criar uma seção visualmente forte antes do rodapé.

Título:

"Qual vai ser o sabor de hoje?"

Texto:

"Escolha seu favorito, monte do seu jeito e peça agora."

Botão grande:

"FAZER MEU PEDIDO"

Criar rodapé profissional contendo:

Logo

Pequena descrição

Links rápidos

Cardápio

Sobre nós

Contato

Adicionar:

© 2026 Açaí Tropical — Todos os direitos reservados.

Adicionar links para:

Política de Privacidade

Termos de Uso

14. Experiência e animações

Adicionar animações sutis:

Fade-in ao entrar nas seções

Hover nos cards

Botões com microinterações

Animação suave nos elementos do hero

Transições suaves

Efeito de elevação nos cards

Scroll suave

Evitar exageros. O site deve continuar rápido e profissional.

15. Responsividade

A landing page deve funcionar perfeitamente em:

Celular

Tablet

Notebook

Desktop

Priorizar a experiência mobile, pois grande parte dos pedidos será feita pelo celular.

No celular:

Menu compacto

Botões grandes

Produtos em cards fáceis de tocar

WhatsApp sempre acessível

Textos bem dimensionados

Checkout/pedido extremamente simples

16. SEO

Adicionar:

Title otimizado

Meta description

Open Graph

Estrutura semântica HTML

H1 único

H2 nas principais seções

Alt text nas imagens

URLs amigáveis

Dados estruturados de negócio local quando apropriado

Sugestão de title:

Açaí Tropical | Açaí, Sorvetes e Milk-Shakes

Meta description:

"Peça açaí, sorvetes, milk-shakes e combos deliciosos. Monte seu açaí do seu jeito e peça pelo WhatsApp."

17. Performance

O site deve ser extremamente rápido.

Utilizar:

Imagens otimizadas

Lazy loading

WebP quando possível

Código limpo

Componentização

Evitar bibliotecas desnecessárias

Animações leves

18. Conversão

A prioridade da página deve ser:

VISITANTE → CARDÁPIO → PRODUTO → WHATSAPP → PEDIDO

Distribuir CTAs estrategicamente ao longo da página.

Não criar uma página apenas bonita. Criar uma página pensada para gerar pedidos e vendas.

19. Resultado esperado

O resultado final deve parecer um site de uma sorveteria/açaiteria profissional que realmente poderia estar funcionando em uma cidade brasileira hoje.

Evitar aparência de template genérico.

Criar uma experiência visual marcante, moderna e deliciosa, fazendo o visitante sentir vontade de pedir açaí assim que entrar na página.

O design deve ser suficientemente profissional para ser utilizado como projeto de portfólio de uma agência/desenvolvedor, podendo posteriormente substituir facilmente:

Nome

Logo

Cores

Produtos

Preços

Fotos

WhatsApp

Endereço

Instagram

Horários

Deixar toda essa estrutura preparada para futura personalização para diferentes sorveterias e açaiterias.
